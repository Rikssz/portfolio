# Riks Sipoviča portfolio

Šajā repozitorijā ir pieejams mans CV, kā arī dažādi personīgie, studiju un tehniskie projekti.

Šeit tiek apkopoti:
- 3D modeļi un 3D drukas projekti;
- elektronikas projekti;
- PCB (spiesto plašu) izstrādes;
- programmēšanas darbi;
- laboratorijas darbi un tehniskie pētījumi;
- prototipi, idejas un citi izstrādātie risinājumi.
